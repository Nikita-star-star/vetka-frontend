# События

## Как кнопка запускает действие

**Событие** — сигнал о действии, например нажатии кнопки, вводе текста или отправке формы. **Обработчик события** — функция, которую программа вызывает, когда событие происходит.

В обычном JavaScript мы использовали `addEventListener`. В React обработчик передают прямо в JSX через свойство `onClick`:

`src/App.jsx`:

```jsx
export default function App() {
  function handleClick() {
    alert('Кнопка нажата');
  }

  return <button onClick={handleClick}>Нажать</button>;
}
```

`alert` — встроенная функция браузера для отображения сообщения. Здесь мы передаём ссылку на функцию `handleClick`. React вызовет её при нажатии.

## Почему нельзя писать onClick={handleClick()}

Скобки `()` означают немедленный вызов. Если написать `onClick={handleClick()}`, функция выполнится во время построения интерфейса, а не при нажатии.

Если нужно передать аргумент, используйте функцию-обёртку:

```jsx
function TaskButton({ id }) {
  function showId(value) {
    alert(`Номер задачи: ${value}`);
  }

  return (
    <button onClick={() => showId(id)}>
      Показать номер
    </button>
  );
}
```

Стрелочная функция вызывается React по клику, а уже она вызывает `showId` с нужным номером.

## Объект события

При вызове обработчика React передаёт **объект события** — данные о произошедшем действии.

```jsx
export default function App() {
  function handleClick(event) {
    console.log(event.type); // click
  }

  return <button onClick={handleClick}>Нажать</button>;
}
```

Событие содержит, например, его тип и целевой элемент. В формах этот объект понадобится для чтения введённых значений и отмены стандартной отправки.

Пока обработчик только показывает сообщение. В следующей лекции он изменит данные, от которых зависит сам интерфейс.


## Всплытие событий

Если вложенная кнопка находится внутри контейнера с `onClick`, нажатие на кнопку может вызвать оба обработчика. Это **всплытие события** — событие проходит через вышестоящие элементы.

```jsx
export default function App() {
  return (
    <div onClick={() => console.log('Контейнер')}>
      <button onClick={(event) => {
        event.stopPropagation();
        console.log('Кнопка');
      }}>
        Нажать
      </button>
    </div>
  );
}
```

`stopPropagation()` останавливает дальнейшее распространение события к родительскому обработчику. Используйте его только тогда, когда родитель действительно не должен реагировать.

`preventDefault()` решает другую задачу: отменяет стандартное действие браузера (например, отправку формы с перезагрузкой), но само по себе не останавливает всплытие.
