# Первый рендер

## Что делает main.jsx

После создания приложения Vite откройте `src/main.jsx`. В React-приложении нужно связать дерево компонентов с настоящим HTML-элементом. Для этого React DOM предоставляет `createRoot`.

Минимальный вариант файла `src/main.jsx`:

```jsx
import { createRoot } from 'react-dom/client';
import App from './App.jsx';
import './index.css';

const container = document.getElementById('root');
const root = createRoot(container);
root.render(<App />);
```

`document.getElementById('root')` находит элемент с идентификатором `root` из `index.html`. `createRoot(container)` создаёт корень React — место, где библиотека управляет интерфейсом. `root.render(<App />)` запускает начальное отображение компонента `App`.

**Рендер** (render) в React — вызов компонентов для получения описания интерфейса. Затем React применяет нужные изменения к DOM. Эти действия полезно различать: *вычислить, что должно быть на экране* и *изменить страницу в браузере* — не одно и то же.

## Что делает App.jsx

Замените `src/App.jsx`:

```jsx
export default function App() {
  return <h1>Моя первая страница React</h1>;
}
```

`App` — компонент. Он является функцией, которая возвращает JSX. `export default` позволяет импортировать основной экспорт файла произвольным локальным именем. Имя компонента начинается с заглавной буквы, чтобы `<App />` отличался от тега HTML.

Сохраните файл. В браузере появится заголовок. Vite отслеживает изменения и обновляет страницу во время разработки. Это **HMR** (Hot Module Replacement) — замена изменённого модуля без полной перезагрузки всего приложения, когда это возможно.

## Как React обрабатывает первый показ

Схема: браузер открывает HTML → загружается `main.jsx` → React получает root → вызывает `App` → вычисляет JSX → создаёт или обновляет DOM. Более детальное описание повторного рендера мы изучим после компонентов и props.

Документация: [Render and Commit](https://react.dev/learn/render-and-commit).
