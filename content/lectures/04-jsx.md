# JSX

## Почему JSX похож на HTML

Созданное приложение уже работает. Откройте `src/App.jsx`. Мы заменим демонстрационный код своим.

**JSX** — синтаксис, позволяющий описывать HTML-подобные элементы внутри JavaScript. React использует такое описание, чтобы создать или обновить элементы страницы.

`src/App.jsx`:

```jsx
export default function App() {
  return (
    <main>
      <h1>Мои задачи</h1>
      <p>Пока задач нет.</p>
    </main>
  );
}
```

Это полноценный компонент. `function App()` объявляет функцию; `return` возвращает описание интерфейса. `export default` обозначает основной экспорт модуля. `src/main.jsx` импортирует этот компонент и выводит его на страницу. Пока файл `main.jsx` менять не нужно.

## Отличия от HTML

В JSX указывают `className` вместо `class`, `htmlFor` вместо `for` в `<label>`. Каждый открытый элемент должен быть закрыт: `<img />`, `<input />`. Компонент возвращает один корневой JSX-узел; при необходимости можно использовать пустую обёртку `<>...</>`, называемую **Fragment**.

## Значения внутри разметки

Фигурные скобки внутри JSX позволяют вставить **JavaScript-выражение** — часть кода, которая вычисляется в значение.

```jsx
export default function App() {
  const title = 'Изучить React';
  const done = false;

  return (
    <main>
      <h1>Мои задачи</h1>
      <p>{title}</p>
      <p>{done ? 'Готово' : 'В работе'}</p>
    </main>
  );
}
```

`? :` — **тернарный оператор**: короткая форма выбора одного из двух значений. Если `done` истинно, выводится «Готово», иначе — «В работе».

Важно: JSX содержит выражения, но обычную инструкцию `if` нельзя написать непосредственно внутри `{}`. При сложной проверке вычислите результат до `return`.

## Добавление CSS

Создайте или измените `src/App.css`:

```css
main {
  max-width: 700px;
  margin: 40px auto;
  font-family: sans-serif;
}
```

Подключите файл в начале `App.jsx`:

```jsx
import './App.css';
```

Это обычный импорт CSS из модуля. Браузер покажет заголовок и информацию о задаче по центру страницы. В следующей лекции мы превратим повторяющийся фрагмент разметки в самостоятельный компонент.


## Как JSX превращается в JavaScript

JSX — не текстовая HTML-строка. Инструмент сборки преобразует JSX в вызовы JavaScript, которые создают описание React-элементов. Не нужно запоминать внутренние функции преобразования, но важно понимать, почему браузер не обязан читать исходный `.jsx` как обычный HTML.

В JSX JavaScript-выражение внутри `{}` вычисляется во время рендера. Например, `{2 + 3}` даёт `5`, а `{user.name}` — значение свойства. Нельзя напрямую отобразить произвольный объект как текст: сначала выберите нужное свойство.

React автоматически экранирует обычные строковые значения в JSX. Не нужно вручную создавать HTML-строки, чтобы показать пользовательский текст.

## JSX не является строкой HTML

Вспомним разницу: строка `'<h1>Привет</h1>'` — просто текст. Выражение `<h1>Привет</h1>` внутри JSX после обработки инструментами разработки превращается в описание React-элемента. **React-элемент** — объект-описание того, что нужно отобразить; он ещё не является DOM-узлом браузера. React DOM использует такое описание в процессе обновления интерфейса.

В JSX разрешены JavaScript-**выражения**, которые вычисляются в значение: `{name}`, `{2 + 3}`, `{task.done ? 'Готово' : 'В работе'}`. Инструкцию `if` непосредственно внутри `{}` написать нельзя. Для сложной логики сначала вычислите переменную до `return`.

## Безопасная подстановка текста

```jsx
export default function App() {
  const username = '<script>alert(1)</script>';
  return <p>{username}</p>;
}
```

На экране появится буквальный текст со скобками, а не выполнится скрипт. React экранирует обычные текстовые значения JSX. Поэтому избегайте прямой вставки произвольного HTML через `dangerouslySetInnerHTML` без отдельной необходимости и санитарной обработки.

## Как исправлять ошибки вложенности

Неправильно: два корня подряд без общего контейнера, незакрытый `<img>` или вложенный `<button>` в другой `<button>`. Правильно — одна корневая оболочка или Fragment, самозакрывающийся элемент `<img />`, корректная HTML-семантика. JSX близок к HTML, но требует более строгих правил записи.
