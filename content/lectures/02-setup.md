# Создание проекта

## Что необходимо установить

React-проект — это набор файлов JavaScript, CSS и настроек. Для работы с ним нужен **редактор кода**, то есть программа для удобного редактирования файлов. Используем [Visual Studio Code](https://code.visualstudio.com/download).

Также требуется **Node.js** — среда выполнения JavaScript вне браузера. Она нужна для запуска инструментов разработки, а не для выполнения интерфейса React у пользователя. Скачайте актуальную LTS-версию с [официального сайта Node.js](https://nodejs.org/en/download). **LTS** означает версию, рассчитанную на длительную поддержку.

В составе Node.js поставляется **npm** — инструмент для установки готовых JavaScript-пакетов. **Пакет** — опубликованный набор кода; **зависимость** — пакет, необходимый нашему проекту.

## Что такое терминал

**Терминал** — окно ввода текстовых команд. В VS Code откройте меню Terminal → New Terminal.

Проверьте установку:

```bash
node --version
npm --version
```

Команды должны показать номера версий. Если терминал сообщает, что команда не найдена, перезапустите VS Code после установки Node.js.

## Создание проекта

**Vite** — инструмент, который создаёт исходный проект, запускает сервер разработки и собирает готовые файлы. [Официальное руководство Vite](https://vite.dev/guide/).

Введите в терминале:

```bash
npm create vite@latest task-manager -- --template react
cd task-manager
npm install
npm run dev
```

Первая команда создаёт папку `task-manager` с шаблоном React. `cd` переходит в папку. `npm install` устанавливает зависимости проекта. `npm run dev` запускает **сервер разработки** — программу, которая выдаёт браузеру файлы и обновляет страницу при сохранении изменений.

Откройте адрес, показанный терминалом (обычно `http://localhost:5173`). `localhost` — ваш компьютер; число после двоеточия — **порт**, по которому доступен сервер.

Если видите демонстрационную страницу Vite/React, проект создан успешно.

## Как устроены основные файлы

- `package.json` содержит сведения о проекте, зависимости и команды npm.
- `index.html` — начальный HTML-документ с контейнером приложения.
- `src/main.jsx` подключает React к контейнеру.
- `src/App.jsx` содержит корневой компонент, который мы скоро изменим.
- `src/index.css` и `src/App.css` — стили.

Расширение `.jsx` означает, что в JavaScript-файле используется синтаксис JSX. Он будет разобран в следующей лекции.

Остановить сервер можно сочетанием `Ctrl+C` в терминале. Запустить снова — `npm run dev` из папки проекта.


## Первый запуск: что проверить

После `npm run dev` в терминале должен появиться локальный адрес. Если его нет, посмотрите текст ошибки: сообщение `command not found` обычно указывает на проблему установки Node.js, а сообщение о несуществующем `package.json` — на запуск команды не из папки проекта.

В `index.html` обычно есть `<div id="root"></div>`. Это контейнер для React. **Точка входа** — файл, с которого запускается код приложения: для нашего шаблона это `src/main.jsx`. Пока не изменяйте структуру: в следующей лекции разберём её шаг за шагом.

## Для чего Vite нужен во время обучения

Исходные файлы React используют `import` и JSX. Браузер не обязан понимать JSX непосредственно. **Сборщик** преобразует исходные файлы в форму, которую браузер может выполнить. Vite предоставляет сервер разработки, а при публикации собирает готовый вариант. Это не часть React: React отвечает за UI, Vite — за процесс разработки и подготовки файлов.

После `npm run dev` терминал остаётся занят сервером — это нормально. Не вводите следующие команды в то же окно, пока сервер работает; откройте второй терминал. Для остановки используйте `Ctrl+C`. Адрес `localhost` обозначает текущий компьютер, а не общий адрес в Интернете.

## Проверка работоспособности

1. Откройте `src/App.jsx` и найдите заголовок демонстрационного интерфейса.
2. Измените его текст и сохраните файл.
3. Вернитесь в браузер: Vite обычно обновит страницу автоматически. Это **горячее обновление** — перенос изменений из исходного кода в приложение во время разработки.
4. Откройте Console через инструменты разработчика. Если модуль не найден или JSX содержит ошибку, подробности обычно появятся здесь и в терминале.

**Распространённые проблемы:** `node: command not found` означает, что Node.js не установлен или не доступен из терминала; `package.json not found` обычно означает, что команда выполнена не из папки проекта; занятый порт приводит к выбору другого адреса — используйте именно тот, который показал Vite.
