# Что такое React

## Почему обычного HTML бывает недостаточно

HTML описывает структуру, CSS — оформление, а JavaScript меняет страницу при взаимодействии с человеком. В небольшой странице можно найти элемент через `document.querySelector` и заменить его `textContent`. Если один список одновременно влияет на счётчик, фильтр, несколько карточек и форму, изменения приходится вручную согласовывать друг с другом.

**React — библиотека JavaScript для построения пользовательских интерфейсов.** Библиотека — готовый набор функций, которые приложение использует, когда они нужны. React не заменяет JavaScript и HTML: разработчик продолжает использовать их, но описывает результат, который должен появиться на экране.

## Императивный и декларативный подход

**Императивный** код перечисляет действия: найди элемент, поменяй его текст, спрячь кнопку. **Декларативный** код описывает конечный интерфейс при заданных данных.

Обычный JavaScript (допустим, в HTML уже есть `<p id="status"></p>`):

```js
const paragraph = document.querySelector('#status');
paragraph.textContent = completed ? 'Готово' : 'В работе';
```

В React идея выглядит так:

```jsx
<p>{completed ? 'Готово' : 'В работе'}</p>
```

Здесь `completed` — логическое значение. JSX пока не требуется запускать: в следующих лекциях мы разберём его синтаксис. Разница в ответственности: в React описывается *содержимое*, а нужное обновление DOM выполняет библиотека.

## Компоненты и дерево интерфейса

**Компонент** — самостоятельная часть интерфейса, например карточка задачи. Компоненты можно объединять: страница содержит список, список содержит карточки. Так получается **дерево компонентов** — структура вложенных частей интерфейса.

**DOM** — представление HTML-документа в браузере. React вычисляет описание интерфейса из компонентов, а затем меняет соответствующие DOM-узлы. Не нужно думать, что React полностью перестраивает HTML при каждом изменении: отдельный вызов компонента и реальное изменение DOM — разные этапы.

## Что React не делает

React не предоставляет автоматически сервер, базу данных и права доступа пользователей. Он отвечает за интерфейс. Для локального приложения нам понадобится Vite — средство создания проекта и его запуска. Сначала установим инструменты, затем увидим первый компонент в браузере.

Подробнее: [React — Quick Start](https://react.dev/learn), [Metanit — React](https://metanit.com/web/react/).

## Что именно React берёт на себя

Рассмотрим знакомую задачу: показать число невыполненных задач. В обычном JavaScript мы можем найти HTML-элемент, вычислить число и вручную заменить его `textContent`. После добавления задачи придётся помнить о повторном вычислении, обновлении числа, изменении списка и пустого состояния. Если один обработчик забудет обновить часть экрана, данные и отображение разойдутся.

В React мы описываем зависимость интерфейса от данных. Например, предложение «если задач нет — показать сообщение, иначе — список» превращается в условие внутри JSX. React вычисляет новое описание после изменения состояния и применяет необходимые изменения к странице. Такой стиль называется **декларативным**: мы задаём желаемый результат. **Императивный** стиль описывает конкретную последовательность операций с DOM. Ни один подход не запрещён, но React делает декларативный основным.

React не создаёт базу данных, не предоставляет готовый сервер и не заменяет CSS. Его задача — связывать состояние приложения с пользовательским интерфейсом. В браузере применяется библиотека `react-dom`, которая умеет отображать компоненты в DOM.

## Как читать примеры в дальнейших лекциях

Мы будем указывать файл `src/App.jsx`, когда код можно заменить целиком в основном компоненте. Код вида `function Counter() { ... }` без импорта `useState` — это лишь фрагмент для разбора; для самостоятельного запуска используйте полный пример с необходимыми импортами. Обозначение `...` внутри обычного текста означает пропущенные детали, а не рабочую инструкцию JavaScript. Не путайте его с оператором `...` в настоящем JavaScript-коде.

**Наблюдаемый результат:** при первом знакомстве с React достаточно понимать: HTML и CSS продолжают использоваться, но за обновление интерфейса по изменившимся данным отвечает React. Следующая лекция создаст проект и покажет, где эти части соединяются.
