# Компоненты

## От повторяющейся HTML-разметки к компоненту

Представьте список из десяти задач. Для каждой требуется заголовок и статус. Копировать одинаковые фрагменты JSX неудобно.

**Компонент React** — функция, которая возвращает JSX и может использоваться как собственный элемент интерфейса. Имя компонента пишется с заглавной буквы, чтобы React отличал его от обычного тега HTML.

Создайте `src/TaskCard.jsx`:

```jsx
export default function TaskCard() {
  return (
    <article>
      <h2>Изучить React</h2>
      <p>В работе</p>
    </article>
  );
}
```

Здесь `article` — семантический HTML-элемент для самостоятельного фрагмента содержания. Компонент возвращает разметку карточки.

## Использование компонента

Замените `src/App.jsx`:

```jsx
import TaskCard from './TaskCard.jsx';

export default function App() {
  return (
    <main>
      <h1>Мои задачи</h1>
      <TaskCard />
      <TaskCard />
    </main>
  );
}
```

`import` подключает основной экспорт файла. Тег `<TaskCard />` говорит React отобразить результат функции `TaskCard`. На экране окажутся две одинаковые карточки. Мы не вызываем её вручную как `TaskCard()` — React сам вызывает компонент в процессе отображения.

## Композиция

**Композиция** — создание большего интерфейса из меньших компонентов. Например, `App` объединяет заголовок и несколько `TaskCard`. Это позволяет изменять карточку в одном месте.

Пока обе карточки одинаковы. В следующей лекции научимся передавать в них разные данные, не создавая отдельную функцию для каждой задачи.


## Компонент — не обычная функция, вызываемая вручную

Хотя компонент записывается как функция, его следует использовать в JSX: `<TaskCard />`, а не вызывать `TaskCard()` прямо при построении дерева. React отвечает за порядок вызовов компонентов, их состояние и связь с деревом. Прямой вызов ломает эту модель, особенно когда появятся хуки.

**Чистый компонент** для одинаковых props/state должен возвращать одинаковое описание интерфейса и не выполнять побочные действия во время рендера. Например, отправка сетевого запроса в теле компонента может запускаться повторно при каждом рендере. Для действий пользователя служат обработчики, для синхронизации с внешними системами — эффекты.
