# Лабораторная работа №2. Интерактивный список задач

## Постановка задачи

Развивайте приложение первой лабораторной. Теперь пользователь должен иметь возможность создавать, изменять и удалять задачи через интерфейс. Данные пока хранятся в React-state и могут исчезать после перезагрузки страницы.

Работа выполняется после лекции «Общее состояние компонентов».

## Требования

1. Все задачи хранятся в одном массиве состояния.
2. Форма добавления задачи содержит поле названия и кнопку отправки.
3. Пустые названия и названия короче трёх символов не принимаются.
4. Новая задача появляется в списке без обновления страницы.
5. У каждой задачи есть кнопки «Выполнено/Вернуть» и «Удалить».
6. В интерфейсе показываются общее число задач и число выполненных.
7. Есть выбор фильтра: все, активные, выполненные.
8. Когда задач нет или фильтр не находит совпадений, показывается понятное сообщение.
9. Все операции со state выполняются без прямой мутации массива или объектов.
10. Для формы, списка и карточки используются отдельные компоненты.

## Порядок выполнения

1. Перенесите массив задач в `useState` внутри `App`.
2. Передавайте список через props в `TaskList`.
3. Реализуйте добавление задачи через форму. Нажатие Enter должно работать.
4. Примените `trim` и валидацию. Ошибку показывайте текстом рядом с полем.
5. Добавьте уникальный `id` для каждой новой задачи.
6. Реализуйте удаление через `filter`.
7. Реализуйте изменение статуса через `map` и spread объекта.
8. Добавьте вычисляемые счётчики, не создавая отдельный state для числа выполненных.
9. Добавьте state для выбранного фильтра и вычисляйте отображаемые задачи на основании `tasks` и фильтра.
10. Проверьте пустое состояние и сценарии, когда результат фильтрации пуст.
11. Убедитесь, что компоненты разделены по ответственности: форма не хранит весь список, карточка не управляет глобальным массивом.

## Подсказки

Вспомните функциональную форму обновления:

```js
setTasks((previous) => [...previous, newTask]);
```

Удаление:

```js
setTasks((previous) => previous.filter((task) => task.id !== id));
```

Вычисляемое число выполненных:

```js
const completed = tasks.filter((task) => task.done).length;
```

Не выполняйте `tasks.push(...)` и не пишите `task.done = true` непосредственно в старом массиве состояния.

## Ожидаемый результат

Пользователь может добавлять задачи, переключать выполнение, удалять и просматривать только активные/выполненные. Счётчики согласованы со списком. После любого действия интерфейс обновляется без перезагрузки.

## Критерии проверки

- Все операции работают последовательно, включая несколько добавлений подряд.
- Не нарушены правила хуков.
- Некорректные значения не сохраняются.
- `TaskList` не хранит копию массива задач в своём state.
- Кнопки доступны с клавиатуры.
- Нет ошибок и предупреждений React.
