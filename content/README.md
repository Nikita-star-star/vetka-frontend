# React: от компонентов до оптимизации

Последовательный курс React для студентов, которые уже знакомы с HTML, CSS и базовым JavaScript. Основной язык примеров — JavaScript с JSX. Студент последовательно освоит компоненты, рендеринг, управление состоянием, основные хуки, работу с API, маршрутизацию и обоснованную оптимизацию.

Для запуска примеров понадобятся [Node.js](https://nodejs.org/en/download), [VS Code](https://code.visualstudio.com/download) и проект [Vite](https://vite.dev/guide/).
